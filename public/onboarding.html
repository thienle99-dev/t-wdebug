Welcome to Debug Lens

Inspect frontend behavior and API traffic from the browser, with debugging data stored locally by default.

Get started

  1. Open a supported HTTP or HTTPS webpage.
  2. Click Debug Lens in the toolbar and choose Pick Element.
  3. Hover over the page and click the UI element you want to inspect. Press Escape to cancel.
  4. Review DOM, styles, layout, visibility, accessibility, and related local debug records.

Why Debug Lens needs website access

Persistent HTTP/HTTPS access lets the lightweight content bridge be ready when you explicitly start inspection. It is also used for optional fetch/XHR capture and to correlate local page activity. UI inspection, screenshots, and AI actions remain user initiated.

Privacy

  • Page content, request/response data, and selected-element snapshots stay in local extension storage by default.
  • Nothing is uploaded automatically. AI prompt creation is explicit and secrets are redacted by default.
  • Component screenshots are captured only when you request them. Use Clear history to remove stored debug data.
  • Chrome-protected pages are unavailable. To inspect local files, separately enable Allow access to file URLs in the extension details.

You can change Debug Lens site access from Chrome’s extension settings. Restricting site access may make the page bridge unavailable on pages Chrome no longer allows it to reach.
